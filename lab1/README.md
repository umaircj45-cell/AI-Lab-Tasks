
# AI Lab 1

## Overview
This folder contains the work completed for Artificial Intelligence Lab 1.

## Tasks

### Task 1: AI Timeline
A timeline of important milestones in Artificial Intelligence, including their significance and sources.

### Task 2: Rule-Based Scholarship Screening System
A simple Python program that checks scholarship eligibility using academic score, document completeness, attendance, and disciplinary record.

### Task 3: Turing Test Comparison
A Python comparison of symbolic and threshold-based scholarship decisions, along with a discussion of the limitations of conversational tests.

## Files

- `lab1_rules.py` – Implements the rule-based scholarship screening system and its four test cases.
- `lab1_compare.py` – Compares symbolic and threshold-based decisions.
- `Lab1_Report.docx` – Contains the written report, timeline, test cases, and comparison.

Run the following commands in the terminal:

```bash
python lab1_rules.py
python lab1_compare.py
```
