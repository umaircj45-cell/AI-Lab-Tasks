
# AI Lab 2 - Intelligent Agents & PEAS Framework

## Overview
This lab focuses on intelligent agents, rationality, PEAS specifications, and environment classification.

## Tasks

### Task 1: PEAS Specifications
PEAS specifications for a delivery robot and an LLM-based student-support agent.

### Task 2: Environment Classification
Classification of both agents based on observability and uncertainty, including simplified simulator assumptions.

### Task 3: Stateful Classroom Agent
An extended classroom agent that remembers the previous operating mode and avoids sending repeated commands.

## Files
- lab2_percepts.py - Basic classroom reflex agent.
- lab2_model.py - Extended stateful classroom agent.
- lab2_check.py - Agent test cases.
- Lab2_Report.docx - Complete written report.
- outputs/lab2_trace.txt - Captured program output.
